# pivotable-LED-rail-mount
Pivotable LED Rail Mount
LED Light holder, has attachments for magnets so LED is easily removed. Mounts to a rail and hangs down, you are able to pivot the light to adjust angle 

Made for 31CM light can be found here: https://www.amazon.co.uk/dp/B0CDWSW4SN?ref_=ppx_hzsearch_conn_dt_b_fed_asin_title_1&th=1
